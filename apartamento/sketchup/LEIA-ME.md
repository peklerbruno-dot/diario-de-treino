# Modelo para o SketchUp

Cada .zip traz um arquivo COLLADA (.dae) com o apartamento inteiro de uma das abas do simulador.
Ele tem paredes, pisos, janelas, portas, marcenaria, móveis e eletrodomésticos.

Para abrir:

1. Descompacte o .zip.
2. No SketchUp, vá em **Arquivo › Importar** e escolha o .dae. Se o arquivo não aparecer, troque o tipo para "COLLADA (*.dae)".
3. Salve como .skp.

O modelo:

- **Medidas:** está em centímetros, em tamanho real.
- **Componentes:** cada móvel vem como um grupo com o nome do simulador (Bancada de trabalho, Armário aéreo azul…). Paredes e pisos também vêm separados.
- **Cores:** são cores sólidas, a média de cada material. Texturas de madeira e tecido não vão junto.
- **Malha:** os objetos são malhas de triângulos. Para editar a marcenaria a fundo, use a malha como referência e redesenhe a peça.
